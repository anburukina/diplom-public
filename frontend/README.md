# Интерфейс оператора (гидро/аэропоника)

SPA на React + Vite с макетом экранов из ТЗ: дашборд, зоны, детальная зона, датчики, журнал ошибок, отчёты.
Данные берутся из `src/data/mockApi.js` (эмулирует REST API, обновляет показания каждые 1–3 c).

## Быстрый старт

```bash
cd frontend
npm install
npm run dev   # dev-сервер
npm run build # сборка
```

После `npm run dev` фронт будет доступен на http://localhost:5173.

## Что реализовано

- Дашборд: агрегаты температуры/влажности/CO₂, график микроклимата, последние ошибки, сводка NDVI по зонам.
- Зоны: поиск/фильтр, статус, NDVI, переход в детали.
- Детали зоны: паспорт, текущие параметры с подсветкой выхода за эталон, графики микроклимата/раствора/NDVI, ошибки зоны, экспорт CSV, автообновление.
- Датчики: список с последним значением и диапазоном измерений.
- Ошибки: фильтры по зоне/уровню, экспорт CSV.
- Отчёты: средний NDVI и статистика аварий по зонам за выбранный период, экспорт CSV.

UI на русском, адаптив до 1366×768, цвета и статусные плашки для аварий/предупреждений. Для подключения к реальному backend замените вызовы из `src/data/mockApi.js` на запросы к API из ТЗ.
